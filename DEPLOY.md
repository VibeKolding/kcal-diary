# Как выложить приложение, чтобы им пользовались другие

Приложение статическое: это набор файлов, которому не нужен ни сервер,
ни база данных. Поэтому его можно бесплатно разместить где угодно.

## Что получится

Вы даёте человеку ссылку. Он открывает её и ставит дневник на домашний экран.
Дальше приложение ведёт себя как обычное: своя иконка, полный экран без
адресной строки, работает без интернета. Внутри, в разделе «Профиль»,
есть карточка с кнопкой установки и пошаговой инструкцией для iPhone.

Никто ничего не платит — ни вы, ни те, кто ставит.

---

## Вариант 1. Netlify (проще всего, без командной строки)

1. Соберите приложение:
   ```bash
   npm run build
   ```
2. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
3. Перетащите туда папку `dist` целиком.
4. Готово — Netlify выдаст ссылку вида `случайное-имя.netlify.app`.

Имя можно поменять на понятное в настройках сайта. Чтобы обновить
приложение, пересоберите и перетащите папку заново.

## Вариант 2. Netlify или Vercel через GitHub (обновления сами)

1. Залейте проект на GitHub.
2. В Netlify или Vercel выберите «импортировать из GitHub» и укажите репозиторий.
3. Настройки сборки подхватятся сами из `netlify.toml` или `vercel.json`.

Дальше каждый `git push` будет обновлять приложение автоматически.

## Вариант 3. Cloudflare Pages

Настройки те же: команда сборки `npm run build`, папка `dist`.
Файл `public/_redirects` уже лежит в проекте и нужен, чтобы прямое открытие
адреса вроде `/stats` не давало ошибку 404.

## Заголовки безопасности

Netlify и Cloudflare Pages берут их из `public/_headers`, Netlify при сборке
из GitHub — ещё и из `netlify.toml`, Vercel — из `vercel.json`. Все копии
одинаковые, источник правды — `src/app/securityHeaders.ts`, и `npm test`
падает, если копия разошлась с ним. Меняете заголовок — меняйте везде.

Служебные файлы из `public/` (README и промты рядом с картинками, `.DS_Store`
от Finder) сборка из `dist` убирает сама, так что при перетаскивании папки
на Netlify Drop на сайт они не попадут.

## Обязательное условие: HTTPS

Приложение устанавливается на домашний экран и работает без интернета только
по HTTPS. Все перечисленные хостинги дают его сами и бесплатно, ничего
настраивать не нужно. По обычному `http://` установка работать не будет.

## Про GitHub Pages

Там сайт лежит по адресу вида `имя.github.io/название-репозитория/`, а
приложение обращается к файлам от корня (`/data/foods.json`). На GitHub Pages
это сломается. Если очень хочется именно туда — нужно задать `base` в
`vite.config.ts` и пересобрать. Netlify и Vercel такой возни не требуют.

## Что человек увидит на телефоне

- **Иконка** — золотое кольцо с листом на тёмном фоне, тот же знак, что
  на заставке приложения.
- **Подпись под иконкой** — «Калории». Полное название «Дневник калорий»
  видно в списке установленных приложений.
- **При запуске** — Android показывает заставку с иконкой на тёмном фоне,
  дальше идёт собственная заставка приложения.
- **Внутри** — полный экран, без адресной строки и кнопок браузера.

Иконки пересобираются командой:

```bash
python3 scripts/build-icons.py
```

## Как обновлять приложение у людей

Service worker проверяет обновления сам: при каждом запуске, раз в час,
пока приложение открыто, и когда к нему возвращаются из фона. Если новая
версия нашлась во время заставки, она ставится сразу. Если к уже открытому
дневнику — сверху появляется плашка «Доступна новая версия» с кнопкой
«Обновить»: посреди записи страница сама не перезагружается. Данные дневника
при обновлении не теряются: они лежат в браузере отдельно от файлов
приложения.

## Что сказать людям при установке

> Открой ссылку в браузере. На Android появится предложение установить —
> согласись. На iPhone открой в Safari, нажми «Поделиться» внизу экрана,
> пролистай и выбери «На экран „Домой“».

На iPhone это обязательно **Safari**: в Chrome на iPhone установка
на домашний экран не работает.

## Если потом захотите в магазины приложений

Код переиспользуется целиком, переделывать ничего не придётся — нужна только
обёртка (Capacitor) и аккаунт разработчика.

| | Стоимость | Что нужно поставить |
|---|---|---|
| Google Play | $25 один раз | Android Studio |
| App Store | $99 в год | Xcode, только на Mac |

Платит тот, кто публикует. Скачивание для людей бесплатное в любом случае.
