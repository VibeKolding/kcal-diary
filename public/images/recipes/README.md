# Фотографии рецептов

Папка пустая: все 63 рецепта используют рисованные обложки, которые
собираются из состава блюда. Так каталог выглядит единым по стилю.

## Как добавить свою фотографию

1. Положите файл сюда. Оптимально — 640×400, формат WebP, качество около 74:
   такой снимок весит 30–45 КБ.
2. Впишите блюдо в словарь `PHOTOS` в `scripts/build-recipes.py`:

   ```python
   PHOTOS = {
     "Борщ со сметаной": {
       "src": "/images/recipes/borscht.webp",
       "author": "", "license": "", "source": "",
     },
   }
   ```

3. Выполните `python3 scripts/build-recipes.py`.

Фотография заменит рисунок сама. Своим снимкам указание авторства не нужно —
оставьте `author` пустым, и подписи на обложке не будет.

## Если берёте чужую фотографию

Годятся только снимки со свободной лицензией: CC0, общественное достояние,
CC BY, CC BY-SA. Последние две требуют указать автора — заполните `author`
и `license`, и подпись появится на крупной обложке рецепта.

Обычные фотографии из интернета брать нельзя: почти все они защищены
авторским правом, и использование их в приложении будет нарушением.
