# Снимки упражнений

Здесь лежат диптихи: по одному кадру на пару «упражнение × пол», в каждом
две фазы движения рядом. Папка может быть заполнена наполовину: упражнение,
для которого снимка нет, раздел «Зал» просто не показывает, а когда файл
появится — покажет сам. Какие файлы есть, приложение узнаёт из
`src/features/gym/shots.ts`, его пересобирает скрипт раскладки.

## Как класть сюда файлы

Руками — незачем, для этого есть скрипт:

```bash
python3 scripts/add-shots.py "~/Downloads/Упражнения в приложение"
python3 scripts/add-shots.py "<папка>" --dry   # только разбор, без записи
```

Он узнаёт упражнение по имени файла, приводит кадр к 1200 × 800, ужимает до
веса в пределах бюджета и кладёт сюда под правильным именем. Имя файла
может быть человеческим: «Жим штанги лёжа, для женщин.jpg», «гантели с
разворотом жен.jpg» или сразу `chest-incline-db-male.jpg`. Название
сверяется со справочником упражнений; если оно подходит сразу к двум,
скрипт не угадывает, а пишет об этом и пропускает файл — допишите в имя
слово, которое их различает.

## Имя файла

`<идентификатор упражнения>-<пол>.webp` и больше нигде не настраивается —
приложение ищет файл именно по этому пути. Ошибка в имени не роняет экран:
снимок молча не появится, а папка при этом выглядит заполненной. Поэтому
имена сверяются со справочником в `src/ui/images.test.ts` — `npm test`
назовёт лишний файл сам.

## Требования к файлу

| Что | Значение |
|---|---|
| Размер | 1200 × 800 (две панели по 600 × 800) |
| Зазор между панелями | сплошной тёмный, ровно по центру кадра |
| Формат | WebP, качество 82 |
| Вес | до 90 КБ на файл |

Размер и вес выдерживает скрипт, отдельно считать ничего не нужно.

## Что важно в композиции

**Полоса посередине.** Две половины должны быть равными — иначе одна поза
выходит мельче другой. Скрипт раскладки измеряет положение полосы и
отказывается класть кадр, у которого она ушла от середины больше чем на
2 % ширины.

**Слева старт, справа финиш.** Стрелок в приложении нет, поэтому порядок
держится только на договорённости: читают слева направо, и перепутанные
фазы покажут движение задом наперёд.

**Файлы кладутся парами.** У упражнения, которое показано обоим полам, нужны
оба файла. Мужской без женского читается как отношение, а не как
незаполненная папка.

## В установочный кэш не попадают

Их шестьдесят девять, и в предкэше они утроили бы вес установки ради
картинок, до которых дойдёт не каждый. `globIgnores` исключает эту папку, а
правило `CacheFirst` кладёт снимок в кэш при первом открытии карточки:
посмотрели один раз — дальше работает офлайн.
