# Фотографии раздела «Зал»

> Здесь только обложки карточек выбора пола. Снимки самих упражнений лежат
> в [ex/](ex/README.md) и устроены иначе: диптих из двух фаз движения,
> 1200 × 800, по файлу на каждый пол.

Здесь лежат обложки карточек выбора пола. Папка может быть пустой: без
снимков карточка показывает силуэт с подсвеченной группой мышц, и раздел
работает полностью. Фотография просто заменяет рисунок.

## Имена файлов

Имя собирается как `<группа>-<пол>.webp` и больше нигде не настраивается —
приложение ищет файл именно по этому пути. Нужны двенадцать штук:

```
chest-female.webp      chest-male.webp
biceps-female.webp     biceps-male.webp
triceps-female.webp    triceps-male.webp
back-female.webp       back-male.webp
shoulders-female.webp  shoulders-male.webp
legs-female.webp       legs-male.webp
```

Ошибка в имени не роняет экран: карточка молча покажет рисунок. Поэтому
после добавления снимков стоит открыть раздел и убедиться, что подменились
все двенадцать, а не одиннадцать.

## Требования к файлу

| Что | Значение |
|---|---|
| Пропорции | 3:2, горизонтальные |
| Размер | 1040×694 (карточка 520 CSS-пикселей при двойной плотности) |
| Формат | WebP, качество около 78 |
| Вес | до 90 КБ на файл |

Вес важнее, чем кажется: все двенадцать попадают в офлайн-кэш вместе с
приложением, и мегабайт лишних картинок платит каждый, кто его ставит.

Перегнать в WebP можно так:

```bash
cwebp -q 78 -resize 1040 0 chest-female.png -o chest-female.webp
```

## Композиция

Карточка обрезает снимок по `object-fit: cover` при высоте 148 CSS-пикселей —
то есть видна **горизонтальная полоса из середины кадра**. Держите фигуру в
центре по вертикали и не прижимайте к верхнему и нижнему краю: они срежутся.

## Если берёте чужую фотографию

Годятся только снимки со свободной лицензией: CC0, общественное достояние,
CC BY, CC BY-SA. Обычные фотографии из интернета брать нельзя — почти все
они защищены авторским правом.
